# MotiveLife — 45s website product demo

Regenerate:

```bash
python3 scripts/generate-product-demo-video.py
```

Output: `apps/web/public/marketing/product-demo.mp4` (1920×1080, ~45s, narrated).

Uses product screenshots under `apps/web/public/marketing/screenshots/` plus brand logo, Ken Burns motion (ffmpeg), and edge-tts narration.
