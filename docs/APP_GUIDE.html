1. What the app is

MotiveLife is a daily operating system for your life — an AI chief-of-staff that helps you turn voice and thoughts into action across career, money, health, relationships, learning, and habits.

Core promise

One place for goals, tasks, briefing, memories, and a composite Motive Life Score — not another generic chatbot.

Generation-aware UI

Theme and nav labels adapt to your generation cohort (Gen Z → Boomer); features are the same for everyone.

AI layers

Rule-based engines work without OpenAI. When enabled, GPT-4o-mini enhances briefing, reviews, and voice parsing.

10b. Health apps — how connection works

Why web alone isn't enough

Apple Health and Samsung Health do not expose a browser API. Fitbit and similar wearables use OAuth on the server. Phone health data flows: device → MotiveLife app → POST /api/health/sync → Life Score.

Fitbit (web)

Integrations → Connect Fitbit → OAuth → nightly/on-demand sync → HealthMetric rows → auto-update Health targets

Health Connect (Android)

  1. User enables Samsung Health → Health Connect sharing (on Samsung devices)
  2. Opens MotiveLife Android app (Capacitor WebView)
  3. Health page → Sync Health Connect → native permissions → upload to API

Data model

  • HealthMetric — normalized samples (steps, sleep_minutes, resting_hr, active_minutes)
  • HealthItem — user-facing targets; device data rolls up into matching items
  • UserIntegration — Fitbit tokens (same pattern as Google Calendar)

13. User flows

Signup → first day

Register → 14-day trial created → session → /dashboard → Life Focus onboarding (if empty) → optional dashboard tour → daily operating system

Typical day

  1. Open Today — read briefing & Life Score
  2. Complete Life Engine daily action (keep streak)
  3. Work today’s mission and domain next-actions
  4. Voice capture anytime — tasks and memories extracted
  5. Evening: reflection + review
  6. Sunday: weekly letter on dashboard and in Memory

Social

  • Life Circle — invite friends/family, linked accountability
  • Referrals — bonus units when someone signs up with your link
