# Kashu screens

Locked product: **docs/KASHU_MASTER_PLAN.md**. No bank connection. Kashu owns money.

## Home

Safe to Spend, projected low, next payday, model confidence (completeness blended with predicted-vs-actual once two balance updates exist).

**Life OS** strip: KINZO extra km → fuel, DayO calendar travel / pre-payday spend, UPLIFT goal monthly cost verdicts, learning lessons.

Setup loop: income → balance → upload/update → confirm bills. **Talk to Kashu** drafts the model from conversation.

Payday Mode banner when payday is within two days.

## Radar

Horizon 14 / 30 / 60 / 90. Income, bills, lifestyle (including KINZO/DayO extras), collisions.

## Bills

Confirm statement recurrings or enter obligations. Kashu is the only bill engine.

## Update (no bank)

1. Current balance (Buffers tab)
2. Upload PDF/CSV/paste
3. Add transaction / change (optional apply to balance)

Each actual balance teaches predicted vs actual.

## Buffers

Liquid balance, safety floor, emergency reserve (excluded from STS), lifestyle burn, income bands.

## Payday / Timing / Afford / Ask

Payday Mode, bill-timing optimizer, Can-I-Afford-It / What-If, conversational Ask Kashu.

## Transition

Bank Switching Mode — user confirms PADs/payroll. Still no bank login.
